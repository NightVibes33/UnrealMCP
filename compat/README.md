# Unreal compatibility state

This directory is machine-readable state for UnrealMCP's update system.

- `epic-docs.json` tracks official Epic documentation endpoints and the latest
  observed Unreal version.
- `api/` stores live reflected Unreal Python API snapshots generated by a real
  Unreal Editor installation.
- `reports/` stores machine-generated compatibility diffs.

The documentation watcher never rewrites UnrealMCP implementation code from web
text. New APIs become immediately usable through the live discovery and dynamic
invocation tools. Version-specific code changes are only merged automatically
after a real Unreal build/smoke test proves them safe.
