# Unreal compatibility state

This directory is machine-readable state and evidence for UnrealMCP's update system.

- `epic-docs.json` tracks official Epic documentation endpoints and the latest
  observed Unreal documentation version.
- `api/` stores deterministic live reflected Unreal Python API snapshots
  generated by a real Unreal Editor installation.
- `reports/` stores API diffs, direct Unreal smoke results, and native MCP TCP
  bridge smoke results.

Generated evidence intentionally omits timestamps, temporary project paths, and
machine-specific platform strings where they would create meaningless diffs.

The documentation watcher never rewrites UnrealMCP implementation code from web
text. New reflected APIs become immediately usable through live discovery and
dynamic invocation tools. A newly detected Unreal version is only eligible for
automatic compatibility merge after:

1. the real C++ plugin compiles with that engine;
2. direct Unreal editor/subsystem smoke tests pass;
3. the actual UnrealMCP TCP bridge starts headlessly and passes MCP commands;
4. the reflected API diff contains no breaking change referenced by UnrealMCP.
